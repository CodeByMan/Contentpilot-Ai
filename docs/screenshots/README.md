# Screenshot Guidelines

Add sanitized PNG or WebP screenshots for the public README using these suggested names:

- `landing-page.png`
- `sign-in.png`
- `admin-dashboard.png`
- `customer-dashboard.png`
- `templates.png`
- `media-library.png`
- `billing.png`

Use seeded demonstration data only. Remove or blur API keys, email addresses that are not demonstrative, payment references, receipts, notification identifiers, local filesystem paths, and any personal or production information.
